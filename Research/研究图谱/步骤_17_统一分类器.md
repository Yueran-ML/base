## 问题

Stage 0 和 Stage 1 的 `_classify_phase` 实现不同：
- Stage 0：单点检测，gap ≥ 1000 → Grokking
- Stage 1：sustained 检测，tau_gen < 0.33 × max_steps → Comprehension

导致 lr=1.6e-3, wd=2.5 这三个 seed 在两个脚本中被标记为**不同的相区**，尽管底层 tau_gen 值完全一致（~10k–13.5k 步）。

**如果不修：** 方向 1（wd 边界）、方向 2（F<G 反例）、方向 4（跨 prime 比较）都会被污染。

---

## 修复：创建 grok_metrics.py

单一权威来源，所有脚本从此导入。详见 [[概念_相位分类器]]。

```python
# grok_metrics.py — 唯一权威版本
def classify_phase(steps, train_acc, test_acc, grok_gap=2000, n_sustained=3):
    tau_train = find_tau_sustained(steps, train_acc, 0.9, n_sustained)
    tau_gen   = find_tau_sustained(steps, test_acc,  0.9, n_sustained)
    if tau_train is None: return "Confusion"
    if tau_gen   is None: return "Memorization"
    if (tau_gen - tau_train) >= grok_gap: return "Grokking"
    return "Comprehension"
```

## 影响

lr=1.6e-3, wd=2.5：
- 旧（Stage 1）：Comprehension
