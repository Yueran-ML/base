# Circle Score（圆分数）CS(t)

**相关**: [[概念_Fourier对齐]] | [[发现_tau_ring失效]] | [[步骤_05_修复脚本]]

---

## 定义

满足"可容许平行四边形条件"的四元组比例。

**数学背景**：若嵌入完全遵循模块化加法的代数结构，对所有满足 i + j ≡ m + n (mod p) 的四元组 (i, j, m, n)，应有：
$$E_i + E_j \approx E_m + E_n$$

当此条件精确成立时，嵌入向量形成"等间距圆"。

---

## 计算过程

对每个 s = 0, 1, ..., p-1：
1. 找所有满足 i + j ≡ s (mod p) 的词元对 (i, j)
2. 计算向量和 $E_i + E_j$（维度 p × d）
3. 对所有两对计算残差范数：$\|（E_i + E_j) - (E_m + E_n)\|$
4. 若残差 < δ × avg_norm（δ=0.1）则计为"通过"

$$\text{CS} = \frac{\text{通过的四元组数}}{\text{全部四元组数}}$$

---

## 为什么替换了 Procrustes 相似度？

早期使用 Procrustes 相似度（PCA top-2 与标准圆对齐），在**所有 18 个 run** 中均输出 0。

原因：Fourier 结构在 256 维嵌入空间中分散在多个谐波维度，无法集中在 PCA top-2 方向。Circle Score 直接在**全维度空间**中计算，不依赖降维。→ [[步骤_02_Stage0v1运行]]

## tau_ring

- 主要方法：CS ≥ 0.8 持续 3 个 checkpoint
- 备用方法：CS 轨迹的 BIC 变化点（若主要方法失败）

## 最终结果

**tau_ring 从未检测到**：Stage 0 + Stage 1 共 93 个 run，50000 步内 CS 从未持续达到 0.8。CS 有上升趋势但未成型。

→ [[发现_tau_ring失效]]：tau_ring 降级为辅助观察指标，研究主要指标改为 tau_F。
