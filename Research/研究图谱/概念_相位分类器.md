## 演变历史

### Stage 0 版本（已废弃）
```python
def _classify_phase(steps, train_acc, test_acc):
    t_train = next((s for s, a in zip(steps, train_acc) if a >= 0.9), None)
    t_test  = next((s for s, a in zip(steps, test_acc)  if a >= 0.9), None)
    if t_train is None: return "Confusion"
    if t_test  is None: return "Memorization"
    return "Grokking" if (t_test - t_train) >= 1000 else "Comprehension"
```
问题：**单点检测**（非 sustained），1000 步 gap 阈值。

### Stage 1 版本（已废弃）
```python
def _classify_phase(steps, train_acc, test_acc, early_frac=0.33):
    early_cutoff = steps[-1] * early_frac   # = 16667 at 50k steps
    ...
    if tau_gen <= early_cutoff or tau_gen <= 2.0 * tau_train:
        return "Comprehension"
    return "Grokking"
```
问题：`early_frac=0.33` 把 tau_gen=10k（实际是 Grokking）误判为 Comprehension（10k < 16.7k）。

### 统一版本（现行，grok_metrics.py）
```python
def classify_phase(steps, train_acc, test_acc, grok_gap=2000, n_sustained=3):
    tau_train = find_tau_sustained(steps, train_acc, 0.9, n_sustained)
    tau_gen   = find_tau_sustained(steps, test_acc,  0.9, n_sustained)
    if tau_train is None: return "Confusion"
    if tau_gen   is None: return "Memorization"
    if (tau_gen - tau_train) >= grok_gap: return "Grokking"
    return "Comprehension"
```

---

## 规范参数

| 参数 | 值 | 含义 |
|------|-----|------|
| `grok_gap` | 2000 步 | Grokking 与 Comprehension 的分界 |
| `n_sustained` | 3 | 连续 checkpoint 数 |
| `acc_threshold` | 0.9 | 准确率阈值 |

---

## 不一致问题的后果

lr=1.6e-3, wd=2.5 这三个 seed：
- Stage 0：标记为 **Grokking**（tau_gen ≈ 10k，tau_train ≈ 500，gap ≈ 9.5k ≥ 1000）
- Stage 1：标记为 **Comprehension**（tau_gen ≈ 10k < 16.7k = 0.33 × 50k）
- 统一版本：标记为 **Grokking**（gap ≈ 9.5k >> 2000）✓

G<F 分析不受影响（依赖 tau_gen 和 tau_F，与 phase label 无关）。
