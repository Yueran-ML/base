## 基本配置

| 参数 | 值 |
|------|-----|
| 素数 p | 53 |
| 嵌入维度 d_model | 256 |
| 注意力头数 n_heads | 4 |
| 层数 n_layers | 2 |
| 前馈维度 d_ff | 1024 |
| 架构 | Decoder-only Transformer |
| 输入 | 两个词元 [a, b] |
| 输出 | 预测 (a + b) mod p |
| Dropout | 0.0 |

## 优化器配置

| 组件 | 学习率 | 权重衰减 |
|------|--------|---------|
| 嵌入层 | 1e-3（固定）| 0（固定）|
| 解码器 | 扫描变量 | 扫描变量 |

解码器超参数扫描范围：
- lr ∈ [3×10⁻⁷, 4×10⁻²]（对数均匀）
- wd ∈ [10⁻², 30]（对数均匀）

## 数据集

- 总样本：p² = 2809 对（所有 (a,b) 组合）
- 训练集：30%（约 840 样本）
- 测试集：70%
- 对应 MIT 论文（p=97 时约 2800 样本训练集）

## 实现文件

`grokking_baseline.py`：
- `GrokkingTransformer`：模型定义
- `make_dataset(prime, op, seed)`：生成数据集
- `split_dataset(x, y, train_fraction)`：划分数据集
- `build_optimizer(model, decoder_lr, embed_lr, decoder_weight_decay)`：差异化优化器
- `get_token_embeddings(model, prime)`：提取词元嵌入矩阵（p × d）
